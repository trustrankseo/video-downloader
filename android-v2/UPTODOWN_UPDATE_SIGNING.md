# Uptodown Update Signing

Universal Downloader Uptodown update-compatible APKs must use the existing installed-app certificate:

- Alias: `universaltest`
- SHA-256: `14:6B:8D:E2:0D:69:A7:5C:EC:EF:7B:94:9E:22:80:A6:77:9A:E2:59:0E:4E:D2:AF:0C:3F:73:3A:77:4A:F1:ED`

The `uptodownRelease` build type is intentionally separate from Huawei/AppGallery release signing.
